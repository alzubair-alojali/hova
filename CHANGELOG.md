# Changelog

## 0.1.0 — 2026-11-08

- Searchable terminal workspace with keyboard navigation and connection profiles.
- Guided add/edit forms, removal confirmation, and compact terminal layouts.
- Explicit CLI commands for listing, inspecting, adding, editing, removing, and connecting to servers.
- Native OpenSSH connections and import of concrete SSH config aliases.
- Agent-friendly JSON, dry-run argument plans, remote exit codes and bounded execution timeouts.
- Local inventory with validation, private Unix file modes, writer locking, size checks and temporary-file replacement.
- Shell completion, MIT licensing, cross-platform CI and release archives with checksums.
