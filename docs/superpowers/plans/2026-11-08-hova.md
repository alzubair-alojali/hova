# Hova Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. The user authorized implementation and publishing; proceed inline.

**Goal:** Ship a polished SSH address book with interactive and agent-friendly interfaces.

**Architecture:** Validated inventory owns persistence, SSH package produces argument vectors and imports aliases, Cobra exposes explicit actions, Bubble Tea renders the same inventory and actions interactively.

**Tech Stack:** Go 1.24+, Cobra, Bubble Tea v1, Bubbles, Lip Gloss.

**Spec:** ../specs/2026-11-08-hova-design.md

## Global Constraints

- Windows/macOS/Linux; native SSH owns authentication.
- No real inventory, private keys, or passwords in the public repository.
- No implicit connections, local shell execution, or silent overwrites.
- Clean JSON and actionable failures for agents.

## Review Focus

- Malformed inventory must survive failed mutations unchanged.
- Option injection and terminal control characters must be rejected.
- Concurrent writers must not lose records.
- Import must preserve SSH aliases and config without running commands.
- Small terminal sizes, empty searches, cancellation and SSH failures must remain usable.

## Execution record

- User authorized building and public publication; implemented inline without another approval step.
- All initial component tests were run failing before production code. Windows sandbox denied file replacement; the same tests pass with normal Windows filesystem access.
- Independent design review clarified explicit remote shell string semantics, imported alias preservation, and edit behavior.
- Independent release review found concurrent edit overwrites, missing write-size limit, equals syntax parsing, undersized terminal actions, and inherited-pipe timeouts. Each was reproduced by a failing regression and fixed; full suite and go vet pass.
- Minimum workspace size is 24 columns by 18 rows. Below that, connection and edit actions pause until resized.
- Native Windows binary and Linux amd64, macOS arm64 and Windows arm64 cross-builds succeeded before the final review fixes; release CI builds all six combinations from the final source.
- Visual assets were rendered and inspected in headless Chrome; terminal SVG is generated from the real TUI using illustrative data.
- Public repository and v0.1.0 release published. GitHub CI passed on Windows, macOS and Linux, including Linux race detection. Release workflow built all six archives and checksums successfully. Updated main's actions to current v7 runtimes after the first run reported deprecated action runtimes.
