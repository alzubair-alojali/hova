# npm Installation Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans. User approved implementation; execute inline and request an independent final review.

**Goal:** Install and run Hova through npm without a Go installation.

**Architecture:** One dependency-free npm package wraps six bundled binaries. CI builds and verifies the package, and releases attach a ready-to-install tarball.

**Tech Stack:** Node 22+, CommonJS, node:test, existing Go core.

**Spec:** ../specs/2026-11-08-npm-design.md

## Global Constraints

- npm package hova-cli; executable hova; version 0.1.1.
- No runtime downloads, lifecycle scripts, credentials or private inventory in packages.
- Literal argument forwarding, inherited terminal and environment, unchanged exit codes.
- Supported platforms: win32/darwin/linux × x64/arm64.

## Review Focus

- Missing native binary and unsupported architecture yield useful errors.
- Spaces and shell metacharacters survive argument forwarding unchanged.
- Nonzero exits and signals reach calling shells and agents.
- npm tarball includes all six binaries and excludes local/private files.
- Packed and installed package actually runs with install scripts disabled.

- Failing launcher and packaging tests reproduced missing functionality before implementation. Node tests and full Go tests/vet pass locally.
- Independent release review identified Windows packing losing Unix executable modes and a checksum path issue. Public publication is restricted to the Linux-built release archive, CI asserts Unix executable bits, and checksums now use the archive basename.
- CI passed native Go tests on all three operating systems, Linux race detection, and npm launcher/build/install tests on Windows, macOS and Linux with Node 22.
- GitHub v0.1.1 contains the npm tarball and checksum. The downloaded checksum and all four Unix executable modes were independently verified before npm publishing.
- Installed the public GitHub tarball globally with --ignore-scripts; hova.cmd --version returns 0.1.1 and an empty inventory returns []. Actual terminal search and Ctrl+C were smoke-tested through the Node launcher.
- npm initially required account 2FA. User enabled it and completed browser verification; publication succeeded as alzubair_alojali. The public hova-cli@0.1.1 metadata now matches the SHA-512 integrity of the checked release archive. No credentials are included in source or packages.
- Registry installation succeeded after first-publication metadata propagated. The installed hova.cmd reports 0.1.1, a new inventory returns [], and npm exec with the public package reports 0.1.1.
- npm initially cached its temporary 0.0.0-stage publication placeholder locally. A --prefer-online install refreshed that metadata; the plain unversioned install was then repeated successfully, and both hova.cmd and npx report 0.1.1. The registry latest tag is 0.1.1.
